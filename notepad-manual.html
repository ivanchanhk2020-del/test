1. Introduction

Notepad is a simple, fast text editor that has been included with every version of Microsoft Windows. It is designed for editing plain-text files and is one of the most commonly used utilities on the Windows platform.

Notepad is ideal for:

  • Quick note-taking and drafting text
  • Editing configuration files (.ini, .cfg, .conf)
  • Writing and reviewing code or scripts (.html, .css, .js, .py, .bat)
  • Viewing log files and system output
  • Stripping formatting from copied text (paste into Notepad to get plain text)
Note: The Windows 11 version of Notepad introduced a modern design with dark mode, tabs, and an autosave feature. This manual covers both the classic and modern versions.

2. Opening Notepad

There are several ways to launch Notepad on Windows:

Start Menu

Click the Start button, type Notepad, and press Enter.

Run Dialog

Press Win + R, type notepad, and press Enter.

Command Prompt

Open Command Prompt or PowerShell and type notepad. You can also open a specific file: notepad myfile.txt.

Right-Click Context Menu

Right-click on any .txt file and select Open with > Notepad.

File Explorer

Navigate to C:\Windows\System32\notepad.exe and double-click to run.

Create New Text File

Right-click in any folder, select New > Text Document, then double-click the new file to open it in Notepad.

3. Interface Overview

The Notepad window consists of the following elements:

Title Bar

Displays the name of the current file. An asterisk (*) or dot appears if the file has unsaved changes.

Menu Bar

Contains the menus: File, Edit, Format, View, and Help.

Text Area

The main editing area where you type and edit text. This occupies most of the window.

Status Bar

Shows the current cursor position (line and column number), the zoom level, the line ending format (Windows CRLF, Unix LF, or Mac CR), and the file encoding (UTF-8, ANSI, etc.).

Tab Bar Windows 11

In the modern Notepad, a tab bar appears at the top allowing you to work with multiple files in a single window.

4. Creating a New File

To create a new, blank text file:

  1. Open Notepad (the application starts with a blank document by default).
  2. Alternatively, if Notepad is already open, go to File > New or press Ctrl + N.
  3. In Windows 11 Notepad, a new tab is created. In the classic version, a new window opens or the current document is cleared (you will be prompted to save unsaved changes).
  4. Begin typing your content in the text area.
Tip: In Windows 11, press Ctrl + Shift + N to open a new Notepad window instead of a new tab.

5. Opening an Existing File

  1. Go to File > Open or press Ctrl + O.
  2. In the Open dialog, navigate to the location of your file.
  3. By default, only .txt files are shown. Change the file type filter to All Files (*.*) to see all file types.
  4. Select the file and click Open.

Supported Encodings

When opening a file, Notepad automatically detects the encoding. The encoding selector in the Open dialog lets you choose from:

  • UTF-8 — the default and most widely used encoding
  • UTF-16 LE — Unicode with little-endian byte order
  • UTF-16 BE — Unicode with big-endian byte order
  • ANSI — legacy system codepage encoding

7. Find & Replace

Find

  1. Press Ctrl + F or go to Edit > Find.
  2. Type the text you want to search for in the Find what field.
  3. Choose the search direction: Up or Down.
  4. Optionally check Match case for case-sensitive search or Wrap around to search the entire document.
  5. Click Find Next or press Enter to locate the next occurrence.

Replace

  1. Press Ctrl + H or go to Edit > Replace.
  2. Enter the text to find in the Find what field.
  3. Enter the replacement text in the Replace with field.
  4. Click Replace to replace the current occurrence, or Replace All to replace every occurrence at once.
Tip: Use F3 to repeat the last search (Find Next) without opening the Find dialog.

8. Word Wrap

Word Wrap controls whether long lines of text are wrapped to fit within the Notepad window or extend beyond the visible area with a horizontal scrollbar.

Toggling Word Wrap

  • Go to Format > Word Wrap and click to toggle it on or off.
  • When enabled, text wraps at the edge of the window — no horizontal scrollbar appears.
  • When disabled, each line extends to its full length and a horizontal scrollbar appears when lines are longer than the window width.
Note: When Word Wrap is on, the Go To Line feature and the Status Bar line/column display may behave differently in the classic version. The Windows 11 version supports both simultaneously.

9. Font & Appearance

Changing the Font

  1. Go to Format > Font.
  2. Select a Font family (e.g., Consolas, Courier New, Lucida Console).
  3. Choose a Font style (Regular, Bold, Italic, Bold Italic).
  4. Set the Size.
  5. Click OK to apply.
Tip: For editing code or log files, use a monospaced font like Consolas or Courier New so that columns align properly.

Zoom

Quickly change the text display size without altering the font setting:

Dark Mode Windows 11

The modern Windows 11 Notepad supports a dark theme. To enable it:

  1. Click the Settings gear icon (top-right corner).
  2. Under App theme, select Dark, Light, or Use system setting.

10. Saving Files

Save

Press Ctrl + S or go to File > Save. If the file has not been saved before, a Save As dialog will appear.

Save As

Press Ctrl + Shift + S or go to File > Save As to save the file with a different name, location, or encoding.

Encoding Options

When saving, you can select the encoding from the dropdown at the bottom of the Save As dialog:

Autosave Windows 11

Windows 11 Notepad automatically saves your work in the background. If you close Notepad without saving, your unsaved content is preserved and restored the next time you open the application — no manual save required.

11. Printing

  1. Go to File > Print or press Ctrl + P.
  2. Select your printer from the list.
  3. Configure print settings (page range, number of copies, etc.).
  4. Click Print.

Page Setup

Before printing, you can configure the page layout via File > Page Setup:

  • Paper size and orientation (Portrait / Landscape).
  • Margins (left, right, top, bottom).
  • Header and Footer — use special codes to insert dynamic values:
    • &f — File name
    • &d — Current date
    • &t — Current time
    • &p — Page number
    • &l — Left-align
    • &c — Center
    • &r — Right-align

14. Tips & Tricks

Strip Formatting from Text

Copy formatted text from any application, paste it into Notepad, then copy it again from Notepad. The text is now plain text with all formatting removed.

Quick Log File

Type .LOG as the very first line of a file. Each time you open that file, Notepad will automatically append the current date and time at the end — useful for keeping a simple journal or log.

Open Large Files

The modern Windows 11 Notepad can handle much larger files than previous versions. For very large files (hundreds of MB), consider a dedicated editor like VS Code or Notepad++.

Change Line Endings

The status bar displays the current line-ending format. In the Windows 11 version, you can click on it to switch between Windows (CRLF), Unix (LF), and old Mac (CR) line endings.

Use as a Clipboard Scratchpad

Keep a Notepad window open alongside your work to temporarily store text snippets, URLs, or notes you need throughout the day.

Right-to-Left Reading

Press Ctrl + Shift + Right to switch the text direction to right-to-left for languages like Arabic or Hebrew. Press Ctrl + Shift + Left to switch back.

This user manual covers Windows Notepad as included in Windows 10 and Windows 11. Features marked with Windows 11 are exclusive to the modern Notepad app. Microsoft may update features in future Windows releases.
